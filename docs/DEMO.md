# School Assistant Chatbot - Solo Demo

## Demo Script

### 1. Basic Interaction with Solo's Streaming
```
User: Hello
Bot: Hello! I'm your school assistant. How can I help you today?
[Performance: 50ms inference, 75% GPU utilization]
```

### 2. Attendance Query with Solo's Context Management
```
User: How can I check my attendance?
Bot: You can view your attendance records in the attendance section. The records show your daily attendance status and monthly attendance percentage.
[Performance: 45ms inference, 70% GPU utilization]
```

### 3. Grades Query with Solo's Caching
```
User: What is the grading policy?
Bot: The grading system follows a 10-point scale. A grade of 9-10 is excellent, 7-8 is good, 5-6 is satisfactory, and below 5 requires improvement.
[Performance: 35ms inference, 65% GPU utilization, Cache hit]
```

### 4. Complex Query (Solo Model Inference)
```
User: What are the benefits of participating in school sports?
Bot: [AI-generated response about sports benefits]
[Performance: 120ms inference, 85% GPU utilization, Model: mistral-7b]
```

### 5. System Information and Solo Metrics
```
User: What are the system specifications?
Bot: [Displays system information including CPU, GPU, memory, and Solo-specific metrics]
[Performance: 30ms inference, 60% GPU utilization]
```
